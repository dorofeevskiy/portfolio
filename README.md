# Портфолио Матвея Дорофеева

Готовый пакет для GitHub Pages, домен dorofeevskiy.ru. Отдельный платный хостинг не нужен. Сборка и серверный код не нужны.

## Публикация

1. Создать отдельный публичный репозиторий в аккаунте dorofeevskiy, например portfolio.
2. Распаковать ZIP и загрузить содержимое в корень ветки main. В корне должны быть index.html, CNAME, .nojekyll, JS/CSS и каталог assets. Сам ZIP в репозиторий загружать не нужно.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Сначала сохранить Custom domain: dorofeevskiy.ru в Pages, затем менять DNS в REG.RU.
5. Установить A-записи для @: 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153. CNAME для www: dorofeevskiy.github.io. Существующие почтовые записи сохранить.
6. Дождаться проверки DNS и сертификата, включить Enforce HTTPS. Проверка может занять до 24 часов.

Документация: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

GitHub Pages предназначен для демонстрации личных и организационных проектов и имеет ограничения использования и трафика: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

Если публиковать на GitVerse Pages, файлы тоже готовы для статического размещения, но собственный домен сервис сейчас не поддерживает.

Последняя версия сайта: меню и видео закреплены в одном блоке и уходят вверх вместе при переходе к услугам. Ролик 1280×720, 24 кадра/с, 240 ключевых кадров, без изменения байтов. Устаревшие ролики, покадровые картинки и внутренние настройки хостинга в пакет не включены.
